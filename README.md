# AI 简史  （A Brief History of AI）

### AI 很火，但很多人不知道怎么真正用起来

**在AI技术快速变化发展的今天，在社交平台上每天看到各种AI产品：生文案、生图、生视频、生声音、自动写代码，但很多人在下面评论：“我应该怎么用AI？”，身边的同学朋友看到我的机器人，只会加群一起跟机器人玩一玩，可当他想把AI作为生产力工具时，却不知道该从哪开始。**

回到标题《AI简史》，作为天天用AI的人，自然而然的觉得人人都在用AI，可现实是，大部分人从来没用过，没有历史的铺垫，网络上的产品、名词、现象，让你焦虑的无从下手。我希望用这篇文档，从AI的发展历史开始，记录和讲述他的变迁，不讲技术细节，用最简单的概念告诉你每一张AI拼图，让你知道现在的AI能做什么，你需要什么，怎么开始。

---

### 用 What / Why / How 理解每一个概念
- what（是什么）
- why（为什么）
- how（解决了什么问题）

从这三点告诉你，那些让人看不懂的词是怎么一步步走过来的，让你再次看到他时，能摸清轮廓，让你也有系统思维。
